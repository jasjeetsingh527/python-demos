Object-oriented programming concepts and implementations.

**Purpose**: Class inheritance and code reusability

### [abstraction.py](abstraction.py)

### [exerciese_1.py](exerciese_1.py) & [exerciese_2.py](exerciese_2.py)

## Core OOP Principles
- **Inheritance**: Code reusability through parent-child relationships
- **Encapsulation**: Data hiding and controlled access
- **Polymorphism**: Multiple forms of the same interface
- **Abstraction**: Hiding implementation complexity

## Key Concepts
- Class definition and instantiation
- Constructor methods (__init__)
- Instance variables and methods
- Access modifiers (public, private)
- Method overriding
- Code organization and reusability
