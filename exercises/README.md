# Python Exercises 🏋️

Practice exercises and challenges to strengthen Python programming skills.

## Files

### [age_calculator.py](age_calculator.py)
**Purpose**: Calculate user's age based on birth year
- Takes birth year input
- Calculates age using current year (2025)
- Displays formatted result

**Usage**:
```bash
python age_calculator.py
```

### [password_checker.py](password_checker.py)
**Purpose**: Password validation and analysis tool
- Accepts username and password input
- Masks password with asterisks
- Reports password length
- Capitalizes username in output

**Usage**:
```bash
python password_checker.py
```

## Key Concepts Demonstrated
- User input handling
- String manipulation
- Mathematical operations
- String formatting
- Basic validation logic
