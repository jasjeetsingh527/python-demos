# Python Conditions & Control Flow 🔀

Control structures and logical operations in Python.

## Files

### [if_else.py](if_else.py)
**Purpose**: Conditional statements and decision making
- If/elif/else structures
- Truthy and falsy values
- Ternary operators
- Short circuit evaluation

**Key Features**:
- Driving eligibility checker
- Boolean logic examples
- Conditional expressions

### [logical_operators.py](logical_operators.py)
**Purpose**: Boolean logic and comparison operators
- Comparison operators (==, !=, >, <, >=, <=)
- Logical operators (and, or, not)
- Magician skill level checker

### [loops.py](loops.py)
**Purpose**: Iteration patterns and loop control
- For loops with various data types
- While loops
- Loop control (break, continue, pass)
- Enumerate and range functions
- Nested loops
- ASCII art generator exercise

**Key Concepts**:
- Iterating over strings, lists, sets, tuples
- Dictionary iteration with items()
- Performance timing with datetime
- Duplicate detection algorithm

## Usage
```bash
python if_else.py
python logical_operators.py
python loops.py
```
